Calculadora Android en Java

  Descripción del proyecto

Aplicación móvil de calculadora desarrollada en Android Studio utilizando Java para la lógica de programación y XML para el diseño de la interfaz.

El proyecto tiene como objetivo implementar una calculadora sencilla, funcional e intuitiva que permita realizar operaciones matemáticas básicas.

  Funcionalidades

Suma, resta, multiplicación y división.

Operaciones con números decimales.

Botón C para limpiar la calculadora.

Botón ⌫ para eliminar dígitos.

Validación de división entre cero.

Presentación de resultados en pantalla.

Interfaz con diseño oscuro y botones diferenciados por colores.

  Tecnologías utilizadas

Java: lógica y funcionamiento de la calculadora.

XML: diseño de la interfaz de usuario.

Android Studio: entorno de desarrollo.

Gradle: gestión y compilación del proyecto.

Git y GitHub: control de versiones y publicación del código.

  Pruebas realizadas

La aplicación fue ejecutada en un emulador Android, donde se verificó el funcionamiento de las operaciones matemáticas, los números decimales y los botones de limpieza y borrado.

También se comprobó que el proyecto compila correctamente mediante Android Studio.

  Ejecución del proyecto

Descargar o clonar este repositorio.

Abrir el proyecto en Android Studio.

Esperar a que finalice la sincronización de Gradle.

Seleccionar un emulador Android o un dispositivo físico compatible.

Ejecutar la aplicación mediante el botón Run.

  Finalidad académica

Proyecto desarrollado como parte del proceso de aprendizaje de desarrollo de aplicaciones móviles Android, aplicando conceptos de programación en Java, diseño de interfaces XML y control de versiones con GitHub.
